# 学一个说法：COGNITION.md

认知库装的是**语言**：梗、黑话、缩写、谐音。它的键是**文字写法**（含变体），所以以后
`qq_memory search 蚌埠` 能命中。它跨会话共用（所有群、所有私聊读同一份），只写「放之四海
皆准」的意思；某个群内部才懂的暗号属于群记忆，写到那个群的 `MEMORY.md` 里。

**有个图 → 这不是本 skill**：表情包走 `learn-sticker`。图文都有时，图进 `STICKERS.md`、
这个词的用法进 `COGNITION.md`，两边互相写名字。

## 文件

`<memory>/COGNITION.md`（默认 `.qq-memory/COGNITION.md`），用 `qq_memory` 读写，路径写
`COGNITION.md`。**里面不许出现任何文件路径**（`.qq-media/…`、`.qq-stickers/…` 都不行）——
那是 `STICKERS.md` 的事，而且缓存路径迟早失效。

## 怎么弄懂

按代价从低到高，够用就停：

1. **从上下文猜**：读它前后几句（`qq_transcript read`）。很多说法是「在这个语境下的反应」，
   场景本身就是答案 —— 「有人发了个离谱的东西，其他人回『典』」≈ 讽刺地表示「经典操作」。
2. **按读音还原**：同音/近音写法（蚌埠住了 = 绷不住了、尊嘟假嘟 = 真的假的、v50 = 微信 50）
   先按读音还原再理解；还原不出来就按字面接，或直接问「这是啥梗」。
3. **联网查**：二次元 / ACG / 网络流行语相关的先加载 `moegirl` 去萌娘百科查（比搜索引擎准
   也比搜索引擎短）；其它话题用 `web_search`。网上解释往往又长又乱，**只提取一句话的意思**。
   查不到就承认查不到，别编。

弄懂之后**再接着聊**。不要一本正经地给群里科普梗，也不要不懂装懂地顺着用。

## 怎么写

一条一行，字段用**全角竖线 `｜`** 分隔（半角也认，但统一用全角）：

```
- 写法（变体：A / B）｜一句话意思｜怎么用｜来源（可选）｜首见 2026-10-12｜置信：确认
```

- **变体写在同一行的括号里**，别为每个变体复制一条（复制出来的条目迟早互相矛盾）。
- 「置信：确认」= 有人解释过、或反复出现且语境一致；「置信：存疑」= 你自己的推测。
  **存疑条目不会进每轮的热梗段**，只能被 `search` 到 —— 这是刻意的。
- 两个二级标题：`## 黑话与缩写`、`## 谐音与变体`。其余节名也能解析，但不参与分诊。

例子：

```markdown
# 公共认知（语言梗 / 黑话 / 缩写 / 谐音）

## 黑话与缩写
- 典｜讽刺「经典操作」，对离谱但符合预期的行为表示无语｜常单独一条，或「典中典」｜2026-10-12｜置信：确认
- 急了｜对方破防、情绪上头了；带调侃，不是真骂｜别在对方真生气时用｜2026-10-12｜置信：确认

## 谐音与变体
- 绷不住了（变体：蚌埠住了 / 绷不住 / 绷）｜忍不住笑了、情绪崩了｜有人发离谱东西时｜贴吧｜2026-10-12｜置信：确认
```

## 硬性要求

- **只写 `<memory>/COGNITION.md`**（用 `qq_memory`，路径 `COGNITION.md`），不要动别的文件。
- **一条只写一个意思**。同一个说法在不同群里意思不同时，分成两条，各带一句语境。
- **不确定的标「置信：存疑」**，不要给它编一个确定的意思 —— 认知库是以后所有回答的依据。
- **别写成网络词典**：只记真实聊天里遇到过的、以后可能再用到的。
- 涉黄、涉政、地域/性别攻击类的说法：记「这类说法是冒犯性的，不要用」就够了，
  不要解释它、更不要在群里复述。

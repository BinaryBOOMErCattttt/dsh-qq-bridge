# 学一张表情包：STICKERS.md

表情包的身份是**收藏后的文件名**（`.qq-stickers/委屈猫.gif`），不是 `.qq-media/<内容哈希>`
—— 后者是 LRU 缓存，迟早被淘汰，指向它的条目就变成一条死链（真实事故：机器人说「存好了」，
过几天那张图没了）。所以顺序永远是：**先收藏，再写目录**。

`STICKERS.md` 每轮都会以「名字（含义）」的形式进提示词：模型看含义就能判断该不该发，
看裸文件名只能猜或先 `read_image`。这就是这个文件存在的全部理由。

## 两步

### 1. 先收藏

`qq_save_sticker`，三个参数都要：

- `source`：正文里给它的那个路径（`.qq-media/ab12….jpg`），也可以是 http 图片链接；
- `name`：有含义的短名字（`委屈猫` / `笑死` / `摸摸头`）—— 这个名字以后每轮都在眼前；
- `meaning`：一句话说清它表达什么情绪（`委屈、求安慰` / `笑到不行、没眼看`）；
- `scene`（可选）：什么时候用（`对方凶我 / 我装可怜时`）。

工具会顺手往 `STICKERS.md` 的「已收藏」区写一行。**没给 meaning 时它写进「未收藏」区**，
那只是待办，不进提示词 —— 遇到这种情况，下一步用 `qq_memory` 把它补完整。

同名已存在会报错：换个名字，别覆盖别人存的表情。

### 2. 补全 / 修正目录（需要时）

用 `qq_memory` 的 **upsert** 改一条，**别整份重写文件**：

```
action: upsert, path: STICKERS.md,
name: 无语, meaning: 无语、懒得吐槽, scene: 看到离谱发言时,
look: 黄色小团子扁着嘴, image: .qq-stickers/无语.gif
```

- 同名的条目会被**原地替换**，不会多出一条；`image` 必须是 `.qq-stickers/…`，
  给 `.qq-media/…` 会被拒（先收藏）。
- 想删：`action: remove, path: STICKERS.md, name: …`。
- 没给 `meaning` 的条目会进「未收藏」区：**不注入提示词、不参与选择**，要么补含义，
  要么删掉。

### 3. 改名字（别重新存一张）

名字起错了、或者后来觉得另一个名字更贴切，用 **`qq_rename_sticker`**：

```
from: 委屈, to: 难过, meaning（可选）, scene（可选）, look（可选）
```

- 它把 `.qq-stickers/委屈.gif` 真的改成 `.qq-stickers/难过.gif`，`STICKERS.md` 那一条也
  同时搬过去（画面 / 含义 / 场景 / 日期跟着走，不用再写一遍）。
- **绝对不要**用新名字再 `qq_save_sticker` 存一遍：那会在目录里留一张同画面、不同名的
  重复表情，旧名字那条目录也还在，以后两张都会被挑中 —— 而你没有删文件的通道，
  重复了就清不掉。
- 只想**改含义 / 场景**（名字挺好）时用上面第 2 步的 `qq_memory` upsert，按**原来的名字**改，
  同样不要再存一张。
- 新名字已被别的表情占用时会拒绝：换个名字，别去覆盖别人的。

工具生成的行长这样（字段用全角竖线，你不用手写）：

```
- 无语｜黄色小团子扁着嘴｜无语、懒得吐槽｜看到离谱发言时｜.qq-stickers/无语.gif｜2026-10-15｜置信：确认
```

## 怎么弄懂一张图

1. **先看**：`read_image` 读那个路径，看图里的字、画风、角色；看不懂就描述它（「白猫缩成
   一团、眼泪汪汪」）。
2. **看上下文**：这张图是回哪句话的？群里为什么笑？（`qq_transcript read`）
3. **查出处**：二次元 / ACG 的角色、作品、弹幕用语加载 `moegirl` 去萌娘百科查；
   其它用 `web_search`。查不到就写你看到的事实（画面 + 在这个语境里的反应），别编出处。

## 硬性要求

- **`STICKERS.md` 里不许出现 `.qq-media` 路径**：那说明还没收藏，先收藏再记。
- **发表情也只认 `.qq-stickers/`**：回复正文里的 `[[图片: …]]` 只能写收藏目录里的文件
  （`.qq-media/…`、工作目录里的其它图都会被拒）。想让某张图以后能发，只有收藏这一条路。
- **不确定含义就写「置信：存疑」**，或者只写画面不写含义；别给一个错误的意思。
- 一张图只写一条。同一张图重新编码后是同一个收藏文件，别为它再建一条。
- **改名只用 `qq_rename_sticker`**：用新名字再 `qq_save_sticker` 存一遍会留下同画面、
  不同名的重复表情，而你删不掉它。
- 涉黄、涉政、地域/性别攻击类的图：记「这张图是冒犯性的，不要发」就够了，不要描述细节。
- **只写 `<memory>/` 里的文件 + 只往 `<stickerDir>` 里存图**，别的什么都不碰。

# 更新认知：把梗和表情包变成「以后一眼就懂」

你在群里聊天时一定会撞上没见过的说法：「典」「急了」「已阅」「v50」「这个 6」，
或者一张只有图、没有任何文字的表情包。这个 skill 管两件事：**弄懂它**，然后**记下来**。

认知库是**跨会话共用**的（所有群、所有私聊都读同一份），所以只写「放之四海皆准」的
意思；某个群内部才懂的暗号属于群记忆，写到那个群的 `MEMORY.md` 里。

## 文件

`<memory>/COGNITION.md`（默认 `.qq-memory/COGNITION.md`），用 `qq_memory` 工具读写，
路径写 `COGNITION.md`。

## 怎么弄懂一个梗

按代价从低到高，够用就停：

1. **从上下文猜**：读它前后几句（`qq_transcript read`）。很多梗是「在这个语境下的反应」，
   场景本身就是答案 —— 「有人发了个离谱的东西，其他人回『典』」≈ 讽刺地表示「经典操作」。
2. **看那张图**：`[图片: .qq-media/xxx.gif]` 这种路径可以直接 `read_image`。
   图里的文字、画风、人物就是它的意思。看完的结论要写成文字，否则下次还得再看一遍。
3. **联网查**：二次元 / ACG / 网络流行语相关的（梗、缩写、角色、作品、弹幕用语、表情包出处）
   先加载 `moegirl` skill 去萌娘百科查 —— 它比搜索引擎准，也比搜索引擎短；
   其它话题用 `web_search` / `web_fetch`（例如「梗 急了 出处」）。
   网上解释往往又长又乱，**只提取一句话的意思**，别把整段搬进认知库。
   查不到就承认查不到 —— 别编一个看起来合理的解释。

弄懂之后**再接着聊**。不要一本正经地给群里科普梗，也不要不懂装懂地顺着用；
真不懂就直接说「这是啥梗」，那比用错强。

## 怎么记

一条一行，格式固定，方便以后 `search`：

```
- 梗名/写法（别名）｜一句话的意思｜怎么用（可选）｜来源（可选）｜首次见到 2026-10-12
```

例子：

```markdown
# 公共认知（梗 / 黑话 / 表情包）

## 黑话与缩写
- 典｜讽刺「经典操作」，对离谱但符合预期的行为表示无语｜常单独一条，或「典中典」
- 急了｜对方破防、情绪上头了；带调侃，不是真骂｜别在对方真生气时用
- v50｜「微信转我 50」的缩写，纯玩笑式讨钱｜通常回在有人晒吃的时候

## 表情包
- `.qq-media/8f3c1a….gif`｜一张猫疯狂摇头｜表示「不不不」「我拒绝」｜2026-10-12
- 蓝毛女仆捂脸｜自己发的表情包 `笑死.gif`｜意思是笑到不行，略带「没眼看」｜2026-10-10
```

## 硬性要求

- **只写 `<memory>/COGNITION.md`**（用 `qq_memory`，路径 `COGNITION.md`），不要动别的文件。
- **一条只写一个意思**。一个梗在不同群里意思不同时，分成两条，各带一句语境。
- **不确定的别写**。宁可只写「不确定，像是表示无语」，也不要给一个错误定义 ——
  认知库是以后所有回答的依据，写错的代价是一直用错。
- **别把它写成网络词典**。只记你在真实聊天里真的遇到过的；这份文件每次都在提示词的
  索引里占位置（`INDEX.md` 里只出现一行），长到没人读就等于没有。
- **见过一次的别急着下结论**：第一次遇到可以在聊天里问一句「这是啥梗」；
  只有确认了意思（有人解释、或反复出现语境一致）才写进认知库。
- 涉黄、涉政、地域/性别攻击类的梗：记「这类说法是冒犯性的，不要用」就够了，
  不要去解释它、更不要在群里复述。

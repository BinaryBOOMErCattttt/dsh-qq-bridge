# 指令（@bot + 空格 + 指令）

群里发 **`@机器人 空格 指令`**（或部署的唤醒前缀 + 指令）；**私聊直接发指令，不用 @**。
指令由插件在 `admit` 之前分流：能确定性回答的不进模型、零 token；只有创作 / 需要看图的
才交给模型。

## 权限与说明

- **主人**：`resetUsers` 里的 QQ 号（用 `QQBOT_RESET_USERS` 配）；名单为空时第一个私聊联系人。
- **访客**：其余人；`guestCommands: false` 时连公开指令也不能用。
- 权限按**这一轮发言人**判；攒批里混进群友，这一轮就不认主人权限。
- 静默中的群不收指令（`起床` 是唯一例外）；私聊**永远不静默**，所以私聊里总能下指令。
- 天气 / 余额 / 随机表情 / 点歌有 3 秒同会话冷却。
- 点歌只贴链接：`music` 段被 NapCat 拒绝、自定义 Ark 卡片显示「发送者版本过低」，所以不做卡片。
- `语音` 只留框架：仓库不内置任何在线语音服务；要接本地 Kokoro / Piper / 自建服务，在 `tts.js` 用 `registerTtsProvider` 注册，再把 `tts` 打开。
- `模式` / `推理强度` 在群里也能看；切换 / 修改仍只认主人。`guestCommands` 开着时所有人能看，只有主人能改；
  模式落盘在 `cwd/data/mode.json`，重启不丢。
  - 切换会**重建当前会话**（旧会话留在磁盘上当存档），并在切换前保留最近 **6 轮（简洁）/ 15 轮（完整 / 斗图）**
    的转录，挂到下一轮的「本轮情境」里接上话题；只喂一轮，之后自动清掉。
  - 简洁模式只保留聊天 / 记忆 / 静默 / 设置 / 定档：指令只放行 `模式` / `状态` / `设置` / `记忆` / `定档`，
    工具收窄到只读检索 + 记忆 + `qq_quiet` / `qq_settings`；攒批固定 5 秒，主动搭话 / 复读 / 补一句全关，
    群里最近消息只看 6 条，回复硬上限 400 字（完整模式 800）。
  - **斗图模式**：表情常驻、不受心情门控，默认每条回复都带一张；开场提示读一次
    `.qq-stickers/SEMANTICS.md` 建语义印象，之后每轮都把表情目录摆在眼前（不然第二句起
    只剩「别滥用」的旧印象，会整轮只打字）。工具面与完整模式一致；退出时把那一轮会话
    归档到 `data/handoff/archive/`。
- **心情门控**（`moduleEmojiMood`，默认开）：模型被夸 / 被开玩笑时在回复末尾写 `[[mood:upN]]`，
  被指正时写 `[[mood:downN]]`，插件解析后从正文删掉 tag；分数满 `moodTrigger*` 时放行一次表情，
  发出去之后清零。冷场按 `moodDecayIdleMs` 每段 ×0.75，安静到 `moodZeroIdleMs` 归零（没用掉的
  许可一起收回）。完整 / 简洁的单次涨幅与阈值分别由 `moodTagMax*` / `moodTrigger*` 控制。
  用户明确要表情时，由模型调用 `qq_send_image` 并传 `user_requested: true`，插件只放行一次。
  表情语义单独放 `.qq-stickers/SEMANTICS.md`（模板 `deploy/SEMANTICS.md`，存新表情时会自动补一行）。
- 模块开关（`moduleFun` / `moduleLookup` / `moduleReminders` / `moduleTts` / `moduleEmojiMood` / `moduleHandoff` /
  `moduleAutoTool` / `moduleDebug`）可以单独关掉一片指令 / 门控；简洁模式忽略这些开关，只认固定的核心集合
  （`mode.js` 的 `SIMPLE_MODULES`）。定档的模块开关对**兜底**那条路同样有效：关掉之后「睡觉去」不会再自动定档。
- **软命令**（`modelAutoTool`，默认关）：用户用自然语言提要求、消息又不是规范指令时，模型可以调
  `qq_auto_tool` 执行对应的插件指令（「帮我抽个签」→ `抽签`），再用自己的口吻转述结果。只对主人生效，
  而且定档 / 语音 / 随机表情 / 接一个 / 存表情 / 设置这几条**故意不开放**（有副作用或会改配置）。
  简洁模式强制关掉它。
- **话题记忆**（`qq_topic`）：模型把反复出现 / 明显重要的话题登记成 high / medium / low 三档，状态在
  `data/chat-state.json` 的 `topics` 段、另有一份人可读的 `data/TOPICS.md`。high 的短摘要每轮进「本轮情境」；
  超过**模式轮数**（简洁 6 / 其它 15）没再被提到就自动降一档，最低冷区，降档后不再注入。
- **时间**：提示词末尾只给「日期 + 凌晨 / 早上 / 中午 / 晚上」这一档粗时段（每天 00 / 06 / 12 / 18 各变一次，
  不把前缀缓存打穿）；要精确到分钟时由模型调用 `qq_time` 取一次。
- `设置` 的可写范围见 `owner-settings.js`；部署项、`provider` / `model`、访问白名单、凭据、
  整段 `persona` / `instructions` 只读。
